# e4steam 0.3.4

## English

- Six runtime JARs for Minecraft **1.17–26.3**, for Fabric/Quilt, Forge and NeoForge. Choose the file matching your loader and Minecraft range. **No retro artifacts are included in this release.**
- Bundled **Addon API 1.1.0** and Steam lobby support for [Public Servers 0.1.0](https://github.com/K2-Studio-Development/e4steam-Public-Servers/releases/tag/v0.1.0). Install the addon separately; no separate API mod is required.
- LAN settings fixes: numeric defaults, public-world naming, command permissions, screen backgrounds and blur ordering across versions.
- Cross-version integrated-world login and Steam connection fixes, including older Forge releases.

Steam must be running and signed in on each player's computer. Install compatible core and addon builds on both sides. Steam authentication and admission checks remain enabled.

Windows x64 is the primary supported platform. Linux/macOS remain experimental as documented. Automated API, core, headless and artifact checks passed; this does not claim a new complete two-account/cross-platform manual test matrix for every final artifact. Historical manual results are documented in COMPATIBILITY.md.

## Русский

- Шесть JAR для Minecraft **1.17–26.3**: Fabric/Quilt, Forge и NeoForge. Выбери файл для своего загрузчика и диапазона игры. **Ретро-сборок в этом выпуске нет.**
- Встроены **Addon API 1.1.0** и поддержка лобби Steam для [Public Servers 0.1.0](https://github.com/K2-Studio-Development/e4steam-Public-Servers/releases/tag/v0.1.0). Аддон устанавливается отдельно; отдельный мод API не нужен.
- Исправлены значения полей LAN, имя общего мира, права команд, фон и порядок размытия интерфейса.
- Включены исправления входа в одиночные миры и соединений Steam на разных версиях, в том числе старых Forge.

У обоих игроков должны быть совместимые сборки и запущенный Steam с выполненным входом. Проверки Steam и допуска к игре сохранены.

Основная платформа — Windows x64; Linux/macOS остаются экспериментальными. Автоматические проверки API, ядра, серверных точек входа и артефактов пройдены. Они не заменяют ручную проверку каждой финальной сборки двумя аккаунтами. История ручных проверок находится в COMPATIBILITY.md.
