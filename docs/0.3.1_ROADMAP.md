# e4steam 0.3.1 status

Version 0.3.1 is a full release. Integrated-world hosting and Windows x64
dedicated servers are supported. Linux and macOS remain experimental until
their manual matrices are recorded.

## Implemented and automatically verified

- stable Steam-derived offline Minecraft identity, owner protection and
  version-specific login adapters;
- bounded, deduplicated, generation-safe RESET retry and queue backpressure;
- owner-controlled native cache with no-follow type/owner/hash/link checks,
  atomic/process-safe publication and redacted failures;
- loader-independent Java 8 Addon API `1.0.0`, Javadocs, surface/purity audit,
  testkit and compile-tested example;
- loader-native discovery, deterministic dependency/lifecycle management,
  scoped capabilities and production runtime/session/identity/access/lobby
  adapters;
- negotiated namespaced addon channels, required/optional compatibility,
  fragmentation, replay/generation guards, quotas and fair scheduling;
- UDP, UI, commands, config, private storage, localization, logging and bounded
  diagnostics services;
- neutral World Settings, Modpack and Skin contracts, without their separate
  user-facing addons;
- universal macOS Intel/Apple Silicon native selection, pinned hashes, Mach-O
  slice validation and macOS CI audits;
- opt-in Linux x64/macOS x86_64 and arm64 pre-LWJGL overlay relaunch for
  launchers that expose a safe direct Minecraft command;
- anonymous Steam GameServer backend, auth admission, loopback ingress
  guard, private/whitelist/unlisted access, headless loader boundaries and
  strict dedicated TOML;
- Forge `1.7.x`–`1.16.x` and regular Fabric
  `1.14.x`–`1.16.x` Java 8 branch artifacts, including headless Steam
  GameServer entry paths and no single all-retro JAR;
- correctly scoped future loader candidates: Legacy Fabric/Ornithe for
  `1.7.10`–`1.13.2` and Rift for `1.13.2`; these are not current artifacts,
  while retro Quilt remains unsupported;
- non-publishing SHA-pinned CI on Windows, Linux, macOS Intel/arm64 plus retro
  branch build/JAR audit.

## Not included in core

- Public Worlds browser/publishing UI;
- modpack downloading or automatic installation/execution;
- external/offline skin lookup;
- world/server-properties settings UI;
- third-party matchmaking, telemetry and analytics.

Only bounded API contracts exist for separate addons. Without such an addon,
there is no corresponding mode, screen, command, channel, lookup or provider.

## Remaining manual coverage

1. Modern two-client host/join/invite/addon-network/reconnect regression matrix.
2. Native Intel and Apple Silicon macOS Steam host/join/reconnect tests.
3. Expand the verified dedicated matrix beyond the completed Windows x64
   NeoForge 1.21.1, Fabric 26.2 and Forge 1.12.2 one-client joins: add two
   authenticated clients, direct-TCP bypass, stale/replayed ticket, reconnect,
   load and graceful-drain checks on every platform.
4. Every retro branch artifact baseline: client launch, world/LAN host, Steam join,
   movement/chunks, disconnect/reconnect and physical server classloading.
5. Review `DEPENDENCY_LICENSE_REPORT.md` and final runtime JAR hashes.

Linux and macOS combinations remain experimental until their checks pass.
Retro branch artifacts are supported release files; exact test coverage,
reference revisions and attribution are recorded in
[`RETRO_PORTING.md`](RETRO_PORTING.md).
