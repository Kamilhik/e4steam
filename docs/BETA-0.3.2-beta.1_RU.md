# e4steam 0.3.2-beta.1

В бету вошли исправления netdiag.8. Скачать JAR можно в [релизе GitHub](https://github.com/Kamilhik/e4steam-Beta/releases/tag/v0.3.2-beta.1). Выберите файл для своего загрузчика и версии Minecraft.

## Что изменилось

- Исправлено определение фактического UDP-порта Simple Voice Chat после запуска и перезапуска голосового сервера.
- Обновлён экран настроек LAN. Настройки можно открыть и после публикации мира.
- Переключение команд обновляет права подключённых игроков и список доступных команд. Порт уже открытого мира остаётся заблокированным.
- Добавлен запасной способ загрузки скина Mojang по нику Minecraft. Он сохраняет Steam UUID и имя игрока, не заменяет существующие текстуры и уступает установленному Suiranoil/SkinRestorer. Команды `/skin`, загрузка по URL и другие сервисы скинов в эту функцию не входят.
- Убран встроенный белый список e4steam. Проверка Steam, баны и лимит игроков сохраняются.
- Изменение отображения TAB из netdiag.9 отменено.

## API публичных серверов

Addon API 1.1.0 встроен в сборки для Minecraft 1.17 и новее. Аддон получает его через `E4steamApi`; отдельный API JAR в `mods` не нужен. JAR API для разработчиков содержит контракты, а не самостоятельный мод.

`lobbies()` позволяет создавать и искать Steam-лобби, менять метаданные. `publicDirectory()` даёт адрес для публикации активного мира или выделенного сервера, запускает подключение и возвращает его состояние.

Список серверов, интерфейс каталога и сервер хранения записей создаёт аддон. Подтверждение владельца (`attest`) для внешнего каталога пока требует сервер проверки: в этой бете доступен режим разработки с локальным реестром, а обычный реестр получает `UNSUPPORTED / RegistryVerifierUnavailable`. Поэтому API ещё не даёт готовую публикацию в произвольный внешний каталог.

Retro-сборки для Minecraft 1.7–1.16 используют отдельный runtime; поддержку современного Addon API на них эта бета не заявляет.

## Проверки

Результаты сборки и автоматических проверок записаны в `COMPATIBILITY.md`. Проверки компиляции, JAR и стенда интерфейса не заменяют игру с двумя Steam-аккаунтами. Полная игровая проверка этой беты на всех ветках не проводилась.
