# e4steam 0.3.2-beta.4

Кандидат включает переработку настроек LAN для Minecraft 26.3: форма стала
шире, секции получили отдельные панели и границы, а вход в настройки мира
помечен брендом e4steam и подсказкой. Фон панели рисуется через новый хук
экранов Minecraft 26.1+. Для переключателя команд обновляются права мира и
гостей одновременно.

Профиль NeoForge 26.1 после обновления на ядро beta.4 и Public Servers beta.13
запускался, но открытие каталога выявило несовместимый тип
`RenderPipelines.GUI_TEXTURED` и падение при отрисовке. beta.16 убрала падение,
а beta.17 устраняет розовые области, вызванные отсутствующими в 26.1
`minecraft:friends/*` спрайтами. Тестовый профиль обновлён; каталог нужно
повторно открыть в игре.

Также сохранено исправление запуска Minecraft 1.21.1 с NeoForge из beta.3.
См. [список изменений](../CHANGELOG.md) и [таблицу совместимости](../COMPATIBILITY.md).

## Public Servers 0.1.0-beta.17

Аддон включает новую иконку в метаданные и JAR. Выполнена автоматическая
проверка семи runtime-артефактов для Fabric/Quilt, Forge и NeoForge, включая
варианты Minecraft 26.3. Проверка подключения двух игроков через Steam для
этого кандидата ещё требуется.

Установите подходящий JAR ядра e4steam и, если нужен каталог общих миров,
совместимый JAR Public Servers. Для игры через Steam одинаковые версии ядра и
аддона должны быть у обоих игроков.
