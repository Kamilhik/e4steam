# Диагностика и приватность

[English version](DIAGNOSTICS.md)

Команда `/e4steam doctor` нужна, когда Steam-сессия не запускается, не создаётся
приглашение или подключение обрывается до входа в Minecraft. Она не исправляет
ошибку сама, а записывает состояние этапов запуска.

## Что выводит команда

Результат появляется в двух местах:

1. в чате виден короткий статус;
2. в `latest.log` записывается более подробный, но ограниченный отчёт.

| Поле | Что означает |
| --- | --- |
| Steam runtime | Запустился ли Steam API и до какого состояния дошёл |
| Steam session | Остановлена, запускается, открывает мир, подключается или повреждена текущая сессия |
| Local port | Локальный порт моста между e4steam и Minecraft |
| Recorded exception | Первая сохранённая ошибка текущего runtime или сессии |
| Mod hash | SHA-512 установленного JAR; помогает заметить разные сборки у игроков |

`UNHEALTHY` — это общий итог, а не причина. Сначала прочитайте поле
`recorded exception`, затем найдите более ранние строки e4steam в `latest.log`.

## Как собрать полезный отчёт

1. Воспроизведите ошибку один раз. Много повторов засоряют журнал и могут
   спрятать первое полезное сообщение.
2. Не закрывая игру, выполните `/e4steam doctor`.
3. Откройте `logs/latest.log` текущей инстанции.
4. Сохраните полный текстовый файл. На скриншоте обычно не помещается причина и
   плохо читается stack trace.
5. Запишите версии Minecraft, загрузчика, Java и e4steam, операционную систему
   и роль компьютера: хост, гость или выделенный сервер.
6. При ошибке подключения возьмите журналы хоста и гостя от одной попытки.

Если игра упала, приложите ещё и подходящий файл из `crash-reports`. Журнал от
другого успешного запуска не поможет найти причину старого вылета.

## Какие данные скрывает e4steam

Размер встроенного отчёта ограничен 64 КиБ. Глубина исключений и размеры
разделов тоже имеют предел. Хэш JAR вычисляется потоком, поэтому весь файл не
загружается в память.

Перед записью e4steam скрывает:

- адреса `.steam`, содержащие данные текущего подключения;
- строки, похожие на SteamID64;
- поля с названиями password, ticket, token, cookie, GSLT и private key;
- путь к домашней папке пользователя;
- нативные указатели и содержимое пакетов.

Doctor не читает произвольные файлы и ничего не отправляет в интернет. Отчёт
остаётся в локальном журнале Minecraft, пока пользователь сам его не передаст.

## Что всё равно нужно проверить вручную

В `latest.log` пишут Minecraft, загрузчик и остальные моды. Другой мод может
вывести ник, путь, адрес или собственный секрет за пределами блока e4steam.
Перед публикацией прочитайте весь файл.

Если в журнале остался действующий адрес `s-...steam` или `d-...steam`, сначала
закройте и снова откройте сессию. Старые данные подключения перестанут
действовать.

## Диагностика от аддонов

В Addon API 1.0 есть `DiagnosticsService`. Аддону нужна capability
`diagnostics.contribute`. Его код выполняется не в нативном потоке, имеет
тайм-аут две секунды и ограничения на поля и общий объём. После этого ядро ещё
раз применяет фильтрацию.

Через `PrivacyOptions` можно запросить отдельные несекретные идентификаторы
Steam или лобби, только если это разрешит интерфейс хоста. Пароли, билеты и
токены включить нельзя. Аддоны остаются обычными Java-модами, поэтому ставить
нужно только доверенный код.

## Частые результаты

| Результат | Что делать дальше |
| --- | --- |
| Steam runtime упал до получения Steam ID | Откройте [диагностику запуска Steam](STEAM_TROUBLESHOOTING_RU.md) |
| Runtime работает, а session имеет состояние `STOPPED` | Откройте мир для сети или выполните `/e4steam start` |
| Session долго остаётся `STARTING` и заканчивается тайм-аутом | Сохраните полный лог и найдите первую ошибку транспорта, VPN или маршрута |
| Хэши мода у хоста и гостя различаются | Установите один и тот же релизный JAR |
| В e4steam нет сохранённой ошибки | Ищите выше ошибку загрузчика, Mixin, входа Minecraft или другого мода |

Не удаляйте все кэши лаунчера и не скачивайте DLL или `.so` со случайных
сайтов. Дальнейшие действия должны следовать из первой конкретной ошибки.
