# Начало работы с e4steam

[English version](GETTING_STARTED.md)

Здесь описана обычная игра в мире, который хост открыл из одиночного режима.
Для выделенного сервера есть отдельная [инструкция](DEDICATED_DEPLOYMENT.md).

## Что делает e4steam

e4steam передаёт трафик Minecraft через Steam P2P или ретрансляторы Valve.
Хост открывает одиночный мир, выбирает режим доступа и отправляет приглашение
либо короткий адрес `s-...steam`. Пробрасывать порты и искать публичный IP не
нужно.

Это не VPN. Гость получает доступ к открытому миру Minecraft и настроенному
UDP-сервису, а не к файлам или домашней сети хоста.

## Что проверить перед установкой

На каждом компьютере должны выполняться пять условий:

1. Обычный клиент Steam запущен, и пользователь вошёл в аккаунт.
2. У хоста и гостя совпадают версии Minecraft, загрузчика и e4steam.
3. JAR подходит именно для установленного загрузчика и версии Minecraft.
4. Для Fabric и Quilt установлен совместимый Fabric API.
5. Steam и Minecraft запущены от одного пользователя ОС и с одинаковыми
   правами.

Minecraft нужно запускать обычным способом через лаунчер. Не добавляйте лаунчер
в Steam как стороннюю игру и не открывайте его через Steam: это может помешать
сессии, которую e4steam создаёт для App ID 480.

## Как выбрать файл

В названии JAR указаны загрузчик и диапазон Minecraft. Операционная система в
названии не указана, потому что один файл содержит необходимые 64-битные
библиотеки для Windows, Linux и macOS.

| Minecraft | Загрузчик | В названии файла | Дополнительно |
| --- | --- | --- | --- |
| 1.17-1.18.2 | Fabric или Quilt | `fabric-quilt-mc1.17-1.18.2` | Fabric API |
| 1.17.1-1.18.1 | Forge | `forge-mc1.17.1-1.18.1` | Ничего |
| 1.19-1.21.11 | Fabric или Quilt | `fabric-quilt-mc1.19-1.21.11` | Fabric API |
| 1.18.2-1.20.2 | Forge | `forge-mc1.18.2-1.20.2` | Ничего |
| 1.20.2-26.2 | NeoForge | `neoforge-mc1.20.2-26.2` | Ничего |
| 26.1-26.2 | Fabric или Quilt | `fabric-quilt-mc26.1-26.2` | Fabric API |

Retro-релизы используют отдельный JAR для каждой ветки: Forge `1.7.x-1.16.x`
и Fabric `1.14.x-1.16.x`. Для Forge `1.7.x` дополнительно нужен один внешний
JAR UniMixins `0.1.20` или новее. Перед установкой retro-сборки в большой
модпак прочитайте [руководство по старым версиям](RETRO_PORTING.md).

Если название файла и таблица расходятся, остановитесь и проверьте актуальную
[матрицу совместимости](../COMPATIBILITY.md). Переименование JAR не делает его
совместимым с другим загрузчиком.

## Как установить мод

1. Закройте Minecraft.
2. Откройте папку `mods` нужной игровой инстанции.
3. Удалите из этой инстанции старые JAR e4steam. Должен остаться только один.
4. Скопируйте подходящий релизный JAR в `mods`.
5. Для Fabric или Quilt положите туда же Fabric API.
6. Запустите Steam и войдите в аккаунт.
7. Откройте Minecraft обычным способом и проверьте наличие e4steam в списке
   модов или журнале запуска.

Повторите установку у каждого игрока. У аддона могут быть свои требования к
версии Minecraft и загрузчику; они указываются на странице аддона.

## Как открыть мир

1. Зайдите в одиночный мир, который хотите открыть друзьям.
2. Откройте меню паузы и нажмите **«Открыть для сети»**.
3. Выберите режим:
   - **«Для друзей Steam»** принимает совместимых игроков из списка друзей
     хоста;
   - **«Только по приглашению»** принимает участников текущего приватного
     лобби.
4. Подтвердите обычные настройки локального мира Minecraft.
5. Дождитесь зелёного адреса `s-...steam` и кнопок в чате.

Steam-сессия работает, пока открыт этот мир. При выходе из мира или ручном
закрытии соединения она останавливается. Команда `/e4steam start` снова
открывает доступ, если мир ещё запущен.

## Как пригласить друга или подключиться

Хост может нажать синюю кнопку **«Пригласить друзей»**. Если оверлей недоступен,
e4steam может открыть отдельное окно друзей Steam.

У гостя есть два способа входа:

- принять приглашение Steam и подтвердить подключение в Minecraft;
- скопировать зелёный адрес `s-...steam`, открыть **«Сетевая игра → Прямое
  подключение»**, вставить адрес и подключиться.

Короткий адрес действует только в текущей сессии. После повторного открытия
мира создаётся новая сессия, а старый токен перестаёт работать.

## Как закрыть или перезапустить соединение

- Красная кнопка **«Закрыть соединение»** показывает подтверждение и завершает
  текущую Steam-сессию.
- На поддерживаемых ветках `/e4steam stop` делает то же самое командой.
- `/e4steam start` снова открывает мир.
- `/e4steam restart` заменяет зависшую сессию новой.
- `/e4steam doctor` записывает ограниченный локальный диагностический отчёт.

Выход из мира закрывает соединение автоматически, но не завершает Steam.

## Голосовые и другие UDP-моды

Minecraft использует TCP. Дополнительно e4steam может передавать настроенный
UDP-порт. Simple Voice Chat определяется автоматически. Plasmo Voice работает,
когда использует порт Minecraft; для другого UDP-мода можно задать
`voiceChatPort`.

У хоста и гостя должны совпадать версии голосового мода. Успешный вход в мир
ещё не доказывает правильную настройку отдельного UDP-порта, поэтому голос
следует проверять после полной загрузки игрока.

## Обновление старого мира

Перед сменой e4steam, Minecraft или загрузчика сделайте резервную копию мира.

После перехода с e4steam `0.2.4` на `0.3.0+` гость может один раз появиться без
старого прогресса. Новые версии создают стабильный Minecraft UUID из
подтверждённой личности Steam вместо старого Mojang/offline UUID. Если нужно
перенести файл из `world/playerdata`, сначала скопируйте весь мир и не удаляйте
старый файл, пока не проверите инвентарь и позицию нужного игрока.

## Если что-то не работает

Начинайте с видимого симптома:

| Симптом | Что проверить первым |
| --- | --- |
| `SteamAPI_Init failed` | Откройте [диагностику запуска Steam](STEAM_TROUBLESHOOTING.md) |
| Не приходит приглашение | Используйте зелёный адрес; проверьте режим доступа, дружбу и совпадение версий |
| `Недействительная сессия` | Проверьте одинаковую сборку e4steam и подключитесь через текущую Steam-сессию |
| Бесконечное шифрование или загрузка территории | Сохраните `latest.log` хоста и гостя; не меняйте JAR наугад |
| Не работает голос | Проверьте версии голосового мода и UDP-порт на обеих сторонах |
| На Linux/macOS нет оверлея | Сеть продолжает работать; [Unix-реланч](UNIX_OVERLAY.md) нужен только для самого оверлея |

Запустите `/e4steam doctor` и прочитайте раздел
[«Диагностика и приватность»](DIAGNOSTICS.md), прежде чем отправлять журнал.
Скриншот часто скрывает первую полезную ошибку, поэтому лучше приложить полный
текстовый лог.

## Ограничения и безопасность

- В открытом мире действует обычный лимит Minecraft: восемь игроков вместе с
  хостом.
- App ID 480 — общий тестовый Spacewar ID Valve, а не личный идентификатор
  e4steam.
- Наличие сборки для Linux или macOS не означает ручную проверку каждого
  рабочего стола, JVM и загрузчика.
- Адрес подключения считается временной приватной информацией. Если его
  опубликовали, закройте и снова откройте соединение.
- Устанавливайте только доверенные моды и аддоны. Java-моды работают в одном
  процессе игры и не изолированы друг от друга.
