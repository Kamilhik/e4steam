# e4steam на macOS

[English version](MACOS.md)

Для macOS используются те же JAR-файлы e4steam, что для Windows и Linux.
Отдельную сборку скачивать не нужно. Внутри уже лежат библиотеки для Intel и
Apple Silicon. Полная матрица подключений на macOS пока не проверена, поэтому в
версии 0.3.1 эта платформа отмечена как **экспериментальная**.

## Быстрый запуск

1. Установите JAR под свою версию Minecraft и загрузчик.
2. Используйте 64-битную Java той же архитектуры, в которой запущен Minecraft:
   `x86_64` для Intel или Rosetta, `arm64` для нативного запуска на Apple
   Silicon.
3. Запустите обычный клиент Steam для macOS и войдите в аккаунт.
4. Откройте Minecraft из своего лаунчера. Не добавляйте лаунчер в Steam как
   стороннюю игру.
5. Зайдите в одиночный мир, откройте его для сети и подключите друга по адресу
   e4steam или через приглашение.

Сетевое соединение Steam не зависит от оверлея. Даже если Shift+Tab не
открывается, подключение по адресу и передача трафика через серверы Valve могут
работать нормально.

## Архитектура и библиотеки

| Как запущен Minecraft | Какая библиотека используется | Что это значит |
| --- | --- | --- |
| Intel Mac, Java `x86_64` | x86_64 | Нативный запуск на Intel |
| Apple Silicon, Java `arm64` | arm64 | Нативный запуск на Apple Silicon |
| Apple Silicon, Java `x86_64` | x86_64 | Запуск через Rosetta, а не проверка arm64 |

В JAR находятся универсальные `libsteam_api.dylib`,
`libsteamworks4j.dylib` и `libsteamworks4j-server.dylib`. Сборка проверяет их
размер и SHA-256, а CI для macOS дополнительно запускает `lipo`, `otool -L` и
`codesign --verify`. Это подтверждает правильную упаковку файлов, но не заменяет
проверку подключения двух настоящих клиентов Steam.

Нативные файлы распаковываются только в защищённый кэш e4steam. Перед загрузкой
мод проверяет тип файла, ссылки, владельца, размер и хеш. Библиотеки из `PATH`
или случайной папки лаунчера не используются.

## Оверлей Steam

Перезапуск ради оверлея по умолчанию выключен. Включайте его только после того,
как убедились, что обычное подключение по адресу работает.

- Minecraft 1.17 и новее: `overlayRelaunch = true` в
  `config/e4steam.toml`.
- Ретро-сборки на Java 8: JVM-аргумент
  `-De4steam.overlayRelaunch=true`.
- Старые версии Prism/MultiMC, скрывающие прямую команду запуска, не используют
  необязательный реланч и продолжают работу без внедрения оверлея.

На Forge 1.7.x-1.12.x перезапуск на macOS намеренно пропускается. Эти версии
могут создавать несколько окон LWJGL, из-за чего после замены JVM окно игры
исчезает, пропадает из Dock или запускается по кругу. Само соединение Steam при
этом доступно: используйте адрес e4steam или отдельное окно друзей Steam.

Подробности и способ отката: [перезапуск оверлея](UNIX_OVERLAY_RU.md).

## Частые проблемы

### `SteamAPI_Init failed`

Убедитесь, что Steam запущен, выполнен вход и Minecraft работает от того же
пользователя macOS. Закройте оставшиеся процессы Minecraft/Java, перезапустите
Steam и снова откройте игру. Не запускайте лаунчер Minecraft через Steam.

### `Could not verify ownership of the native cache parent`

e4steam не смог безопасно использовать папку нативного кэша. Не отключайте эту
проверку и не раскладывайте библиотеки вручную. Закройте игру, удалите только
папку кэша e4steam, указанную в логе, и дайте моду создать её заново.

### Игра перезапускается, исчезает из Dock или не показывает окно

Выключите необязательный перезапуск оверлея. Удалите JVM-аргумент на ретро-
версиях или задайте `overlayRelaunch = false` на современных. Для сетевого
транспорта перезапуск не нужен.

### Не открывается окно приглашения

Скопируйте зелёный адрес `s-...steam` и отправьте его другу лично. Друг вставит
его в поле адреса сервера Minecraft. Неработающий оверлей ещё не означает, что
соединение Steam сломано.

### Ошибка архитектуры нативной библиотеки

Проверяйте архитектуру процесса Java, а не только модель Mac. Лаунчер через
Rosetta использует библиотеки x86_64. Не смешивайте arm64- и x86_64-файлы
вручную.

## Безопасная диагностика

e4steam не требует `sudo`, не отключает Gatekeeper, не снимает quarantine и не
меняет настройки безопасности macOS. Не выполняйте неизвестные команды ради
запуска скачанного JAR.

Для отчёта укажите:

- модель Mac и архитектуру процессора;
- архитектуру запущенной Java;
- версии macOS, Java, Minecraft, загрузчика и e4steam;
- работает ли вход по адресу при выключенном перезапуске оверлея;
- отдельные результаты хоста, входа, приглашения, relay, отключения и повторного
  входа;
- очищенный вывод `/e4steam doctor`.

Не публикуйте рабочий адрес e4steam, Steam ticket, токены аккаунта и личные
пути. Дополнительно: [диагностика](DIAGNOSTICS_RU.md) и
[ошибки запуска Steam](STEAM_TROUBLESHOOTING_RU.md).
