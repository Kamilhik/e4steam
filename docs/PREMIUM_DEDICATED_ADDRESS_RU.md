# Персональный адрес выделенного сервера

Для современных сборок e4steam Premium, Minecraft 1.17–26.3.

1. Положи подходящий **e4steam Premium JAR** в `mods` сервера. Обычный e4steam рядом не нужен. Запусти сервер один раз и останови его.
2. Открой созданный файл `config/e4steam-premium/dedicated-address.properties` и заполни:

   ```properties
   name=my-server
   key=ТВОЙ_КЛЮЧ_PREMIUM
   ```

3. Запусти сервер снова. Игроки добавляют `my-server.steam` в обычном меню «Сетевая игра». Им подходит бесплатный e4steam или Premium с поддержкой этих адресов; Steam у игроков должен быть запущен.

Имя — от 3 до 32 символов: латинские буквы, цифры и дефис; не начинай и не заканчивай его дефисом. Префиксы `s-`, `d-` и `e4steam-` зарезервированы. Расширение `.steam` в поле `name` необязательно. Не публикуй файл с ключом.

На сервере не нужно устанавливать Steam, входить в аккаунт или сканировать QR. Для Linux x86_64 библиотеки уже внутри JAR: мод сам распакует их при запуске. Linux ARM этой сборкой не поддерживается.

На новой установке Steam-режим включён автоматически. Если ты раньше отключал его в конфиге e4steam, верни включённое состояние. Обычный вход по публичному IP в Steam-режиме заменяется подключением через Steam.

Для поиска имени мод по умолчанию использует **UDP на игровом порту сервера**. Например, при игровом порте 25565 хостинг должен разрешать UDP 25565. Это разрешение настраивается у хостинга или в файрволе; мод не может открыть внешний порт сам. Если ранее указан отдельный query-port, используется он.

Старый отдельный `config/e4steam-premium/license.key` продолжает работать, если поле `key` оставлено пустым. При обновлении сохраняй всю папку `config/e4steam-premium`, особенно `dedicated-name-identity.key`: она подтверждает постоянную личность сервера. Не передавай этот файл другим владельцам серверов.

Имена ищутся через Steam без общего реестра: глобальная уникальность не гарантируется. Выбери другое имя, если оно уже занято. Сохранённый клиентом адрес одиночного мира и адрес выделенного сервера — разные привязки; лучше не использовать одно имя для обоих.
