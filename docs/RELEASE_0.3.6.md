# e4steam 0.3.6

## English

- Join Premium-hosted worlds using personal addresses such as `kamilchik.steam`. Guests use free e4steam and do not need a Premium key. Choosing and publishing a personal name requires Premium.
- Add an optional animated **Open to LAN → Support** window. It follows Minecraft's language (English/Russian) and offers **Open Boosty** and **Back**.
- Fix support-panel blur, browser-link opening and UI timing compatibility on Minecraft 26.x.
- Six free runtime JARs cover Minecraft **1.17–26.3** on Fabric/Quilt, Forge and NeoForge. No Premium activation code or retro JARs are included.

Also included from the previously unpublished 0.3.5 work: dedicated-server reconnection fixes, protection against late close callbacks ending a replacement session, dedicated Steam configuration and startup improvements, and automatic selection of an available LAN port.

Install one JAR matching your Minecraft version and loader; Fabric/Quilt also need Fabric API. Replace the old e4steam JAR. Public Worlds remains a separate addon. Windows x64 is the primary platform; Linux/macOS remain experimental. Automated checks and targeted in-game confirmations do not establish a complete two-account test matrix for every Minecraft patch.

## Русский

- Добавлен вход в миры Premium по персональным адресам вроде `kamilchik.steam`. Гостю достаточно бесплатного e4steam, ключ Premium не нужен. Выбор и публикация собственного имени доступны в Premium.
- В **«Открыть для сети → Поддержать»** добавлено необязательное окно с плавным появлением и закрытием. Язык выбирается по языку Minecraft (русский/английский). Внутри — **«Открыть Boosty»** и **«Назад»**.
- Исправлены размытие панели поддержки, открытие ссылки в браузере и совместимость таймера интерфейса с Minecraft 26.x.
- Шесть бесплатных JAR для Minecraft **1.17–26.3**: Fabric/Quilt, Forge и NeoForge. Активации Premium и ретро-JAR в этом выпуске нет.

Также вошли ранее не опубликованные изменения 0.3.5: исправления повторного подключения к выделенному серверу, защита новой сессии от запоздалых событий закрытого соединения, улучшения конфигурации и запуска выделенных серверов через Steam, автоматический выбор свободного порта LAN.

Установите один JAR для своей версии Minecraft и загрузчика, заменив старый e4steam. Для Fabric/Quilt нужен Fabric API. Public Worlds устанавливается отдельно. Основная платформа — Windows x64; Linux/macOS остаются экспериментальными. Автоматические проверки и отдельные подтверждения в игре не заменяют полную проверку всех версий двумя аккаунтами.
