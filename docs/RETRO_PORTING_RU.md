# Ретро-сборки e4steam

[English version](RETRO_PORTING.md)

Ретро-сборки предназначены для Minecraft 1.7.x-1.16.x и работают на Java 8.
Для каждой ветки выпускается отдельный JAR. Общего файла сразу для всех старых
версий нет.

## Установка

1. Выберите Forge или Fabric под нужную версию Minecraft.
2. Скачайте JAR, в названии которого совпадают загрузчик и ветка Minecraft.
3. Положите только один JAR e4steam в папку `mods`.
4. Для Fabric 1.14.x-1.16.x установите подходящий Fabric API.
5. Для Forge 1.7.x отдельно установите UniMixins 0.1.20 или новее.
6. Запустите Steam, войдите в аккаунт и откройте Minecraft обычным способом.

Обозначение `.x` относится только к одной ветке. Например, файл `mc1.12.x`
собран на 1.12.2 и предназначен для версий 1.12, а не для всего диапазона от
1.7 до 1.16. В первую очередь проверяйте базовую версию из таблицы.

## Как это работает

Старые JAR используют отдельные хуки меню LAN и жизненного цикла Minecraft, но
сетевой транспорт остаётся общим с современным e4steam: Steam Networking
Messages, App ID 480, короткие адреса, повторные попытки и проверяемый нативный
кэш.

После открытия мира мод создаёт дополнительную точку входа только на loopback и
передаёт её порт в Steam-транспорт. При закрытии мира соединение
останавливается. Каждый ретро-JAR также содержит точку входа для физического
выделенного сервера; настройка описана в
[руководстве сервера](DEDICATED_DEPLOYMENT_RU.md).

## Отличия и ограничения

- Нужна Java 8.
- Forge 1.7.x использует внешний UniMixins, чтобы не конфликтовать с уже
  установленными библиотеками сборки.
- На старых версиях часть действий может появляться в чате после **Открыть для
  сети**, а не отдельными кнопками в меню.
- Перезапуск ради оверлея Linux/macOS выключен по умолчанию и для сети не
  нужен. На macOS Forge 1.7.x-1.12.x он намеренно пропускается.
- Результат сборки не заменяет ручную проверку двух клиентов. Точные проверки
  перечислены в [`COMPATIBILITY.md`](../COMPATIBILITY.md).

## Частые ошибки

### Дубликаты `unimixins` или `mixinbooterlegacy`

В сборке установлено несколько копий UniMixins. Для Forge 1.7.x оставьте один
совместимый внешний JAR UniMixins 0.1.20+ и удалите именно дубликаты, указанные
FML. Не удаляйте все библиотеки подряд.

### «Недействительная сессия»

Проверьте одинаковую версию e4steam у участников. Хосту нужно заново открыть
мир и отправить новый адрес. Подключайтесь через адрес e4steam, а не по обычному
LAN-порту. Офлайн-профиль Minecraft допускается только после успешной проверки
соединения Steam.

### Нет кнопки e4steam

Проверьте название JAR и отсутствие второй копии мода. На части старых версий
адрес и действия приглашения появляются в чате уже после открытия мира.

### Spacewar запущен, но адрес не появился

Дождитесь сообщения Minecraft с локальным портом. Если версия поддерживает
команду, выполните `/e4steam start`. На более старой системе команд закройте и
снова откройте мир, затем найдите первую ошибку e4steam в логе.

### Игра зависает или исчезает после перезапуска на Linux/macOS

Выключите необязательный перезапуск оверлея. Сетевое соединение работает без
него. Инструкция: [оверлей на Unix](UNIX_OVERLAY_RU.md).

### Большая сборка падает до меню

Сначала запустите только e4steam и обязательные зависимости загрузчика. Затем
возвращайте моды группами и ищите дубликаты coremod, transformer и нативных
библиотек. Для отчёта нужен первый блок `Caused by`, а не одна последняя строка
`InvocationTargetException`.

## Что написать в отчёте

Укажите точную версию Minecraft, сборку загрузчика, Java 8, ОС, полное имя JAR
e4steam, список coremod и момент ошибки: до меню, при открытии LAN или при
подключении. Перед отправкой удалите рабочий адрес и данные аккаунта.

Техническая архитектура, базовые версии и ссылки на адаптированный код находятся
в [английском документе](RETRO_PORTING.md).
