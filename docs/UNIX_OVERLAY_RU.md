# Перезапуск ради оверлея Steam на Linux и macOS

[English version](UNIX_OVERLAY.md)

Сетевое соединение e4steam работает без встроенного оверлея Steam. Перезапуск
нужен только тем, кто хочет видеть интерфейс Valve по Shift+Tab прямо поверх
окна Minecraft на Linux или macOS.

> **Рекомендуемое состояние:** оставьте перезапуск выключенным. Сначала
> проверьте открытие мира и вход по адресу. Включайте эту функцию только ради
> самого оверлея.

## Какой вариант выбрать

| Ситуация | Действие |
| --- | --- |
| Вход по адресу работает, Shift+Tab не нужен | Ничего не включайте |
| Кнопка приглашения открывает отдельное окно друзей Steam | Можно оставить как есть |
| Minecraft 1.17+ на Linux/macOS | Попробуйте `overlayRelaunch = true` |
| Ретро-версия Minecraft на Java 8 | Попробуйте `-De4steam.overlayRelaunch=true` |
| Старый Prism/MultiMC не показывает безопасную команду запуска | Реланч недоступен; используйте обычную сеть без внедрения |
| Forge 1.7.x-1.12.x на macOS | Не форсируйте перезапуск: он намеренно отключён |
| Игра перезапускается дважды, зависает или теряет окно | Сразу выключите перезапуск |

На Windows эта настройка не используется: там оверлей подключает сам клиент
Steam обычным способом.

## Minecraft 1.17 и новее

Steam должен быть запущен и авторизован. Не добавляйте Minecraft или лаунчер в
Steam как стороннюю игру.

Откройте `config/e4steam.toml` и задайте:

```toml
overlayRelaunch = true
```

Если окружение поддерживается, e4steam один раз перезапустит JVM до создания
основного окна LWJGL. Безопасные аргументы лаунчера сохранятся, установленный
Steam renderer загрузится заранее, а новая JVM получит метку, запрещающую
повторный перезапуск.

Для отключения:

```toml
overlayRelaunch = false
```

## Ретро-версии на Java 8

Добавьте JVM-аргумент:

```text
-De4steam.overlayRelaunch=true
```

Чтобы отключить функцию, удалите его или поставьте `false`:

```text
-De4steam.overlayRelaunch=false
```

Forge 1.7.x-1.12.x создаёт дополнительное окно LWJGL для заставки Forge. На
Linux e4steam запускается до этой заставки и отключает только её значение в
памяти. Файл `config/splash.properties` не меняется.

На macOS для Forge 1.7.x-1.12.x перезапуск пропускается. Иначе новая JVM может
исчезнуть из Dock, потерять окно или уйти в цикл перезапуска. Подключение через
Steam при этом остаётся доступным без оверлея.

Forge 1.13.x-1.16.x использует ранний хук ModLauncher. Новая JVM получает
`-Dfml.earlyprogresswindow=false` и запускается до основного окна игры.

## Prism и MultiMC

Современный Prism обычно передаёт достаточно данных, чтобы e4steam сам
восстановил прямую команду запуска Minecraft. Дополнительный агент не нужен.

Старые версии Prism или MultiMC могут скрывать важные параметры. Если
безопасную команду восстановить нельзя, e4steam отменяет необязательный реланч
и оставляет исходный процесс. Сетевое соединение Steam и вход по адресу
продолжают работать без внедрения оверлея.

## Где ищется renderer Steam

e4steam использует только установленный Valve файл
`gameoverlayrenderer.so` или `gameoverlayrenderer.dylib`. Проверяются обычный
Steam, распространённые пути Flatpak и Snap на Linux, а также стандартное
приложение Steam на macOS.

Путь должен вести на читаемый обычный файл. Существующие `LD_PRELOAD` и
`DYLD_INSERT_LIBRARIES` сохраняются. Новая JVM получает постоянный App ID
Spacewar `480`, чтобы контекст Steam не потерялся при переходе через оболочку
лаунчера или sandbox.

Мод не скачивает renderer, не берёт случайные библиотеки из `PATH`, не меняет
Steam, не просит `sudo`, не отключает Gatekeeper и не устанавливает системные
файлы.

Автотесты проверяют точки входа, упаковку файлов и защиту от циклического
перезапуска. Они не могут подтвердить отображение виджетов Valve на каждом
рабочем столе, лаунчере, выпуске macOS и драйвере.

## Если не сработало

1. Выключите перезапуск и проверьте обычный запуск Minecraft.
2. Проверьте вход по адресу e4steam без оверлея.
3. Закройте все оставшиеся процессы Java/Minecraft.
4. Убедитесь, что Steam и Minecraft запущены одним пользователем ОС.
5. На Linux укажите способ установки Steam: обычный, Flatpak или Snap.
6. Выполните `/e4steam doctor` и прочитайте отчёт перед отправкой.

Двойной запуск LWJGL, повторные перезапуски, исчезновение из Dock, скрытое окно
или зависший фоновый процесс означают, что этот необязательный режим для вашей
сборки нужно выключить.

В отчёте укажите ОС и архитектуру, рабочее окружение, способ установки Steam,
лаунчер, Java, Minecraft, загрузчик, версию e4steam и использование агента. Не
публикуйте рабочий адрес подключения и секреты лаунчера.
